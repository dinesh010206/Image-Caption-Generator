# Image Caption Generator
 Image Caption Generator using the transformers,CNN and LSTM

## Files
- train.py
- predict.py
- evaluate.py
- utils.py

## Requirements
- Python 3.10
- TensorFlow 2.10
- Matplotlib
- pickle
- tqdm
- NLTK(Natural language Tool kit)
- Numpy

## Run
python train.py
python predict.py
python evaluate.py
