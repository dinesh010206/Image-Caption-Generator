# Image Caption Generator
 Image Caption Generator using the transformers,attention mechanism,CNN and LSTM

 ## Datasets
 - Flickr8k_dataset(images)
 - Flickr8k_text(for captions)

## Files
- train.py
- predict.py
- evaluate.py
- utils.py

## Requirements
- Python 3.10
- TensorFlow
- Matplotlib
- pickle
- tqdm
- NLTK(Natural language Tool kit)
- Numpy
